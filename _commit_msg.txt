Spectrogram: 3-D surface dock + breathing overlay (V2)

* New Spectrogram3DPlotWidget renders each epoch's sliding-window PSD
  grid as an interactive 3-D surface (time x, frequency y, normalised
  power z + colour), reusing the existing display helpers
  (normalise_grid / downsample_for_surface / epoch_relative_times) so no
  algorithm code lives in the UI. Wired into MainWindow data_specs and
  the View menu (the dock.spectrogram3d placeholder is now live).
* Both the 2-D and 3-D spectrograms overlay the per-window breathing
  frequency (SpectrogramData.resp_freqs) as a green dashed trace when a
  respiration channel is present and the workspace overlay toggle is on.
* Refactored the 2-D and 3-D docks onto a shared _SpectrogramBase
  (_resolve / _compute_epoch) to avoid duplicating the compute path.
