Add pickle cache and the workspace tree right-click menu

Pickle cache (cache_dir/<rawname>.pkl)
- After a data change (R-peak edit, epoch toggle) the edited Session is
  saved to the cache, debounced 1.5 s.
- On load, an existing cache pkl for a raw file is loaded in preference to
  re-parsing the raw — so manual edits persist across sessions.
- The load worker skips the conditioning pipeline for a .pkl (it is already
  processed; re-running would, e.g., flip an already-corrected ECG again).

Tree right-click menu (as in V2)
- Reload raw      : discard the cache pkl and re-parse the raw file.
- Invert ECG polarity : flip the ECG and re-detect (manual override).
- Retrigger R-tops    : re-detect from scratch, discarding manual edits.

spectHR (headless, tested): retrigger_beats and invert_ecg Session->Session
transforms.
